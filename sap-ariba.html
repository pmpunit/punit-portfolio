The problem

Enterprise reporting and machine learning both depend on usable data. Internal teams and customers need ways to bring data together, query it and turn it into something useful without rebuilding the same foundations for each use case.

What I built

Built a shared Data Analytics Platform supporting ad hoc reporting, data queries, third-party data ingestion and processing. The platform also supported machine learning training and natural-language processing use cases.

01Ingest

Bring enterprise and third-party data together.

02Process

Prepare and orchestrate the data.

03Use

Support reporting, queries and ML workflows.

Enabling independence

Built MLTrain, a self-service capability for analysts and data scientists to manage ingestion, processing and orchestration. The focus was to make common workflows reusable and easier to run independently.

The result

70% of paid buyers used the platform’s reporting and analytics capabilities. This work established a foundation for later product decisions involving data quality, context and AI-assisted workflows.
