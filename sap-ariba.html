Look beneath the use cases

Reporting and machine learning serve different needs, but both start with the same work: bringing data together, preparing it and making it usable. Building that foundation repeatedly makes each new use case harder.

Build something reusable

I built a shared Data Analytics Platform supporting ad hoc reporting, queries, third-party data ingestion and processing, with support for machine-learning training and natural-language processing use cases.

01Bring data together

Ingest enterprise and third-party data.

02Prepare it

Process and orchestrate shared workflows.

03Put it to work

Enable reporting, queries and ML.

Help teams use it independently

Built MLTrain so analysts and data scientists could manage ingestion, processing and orchestration through self-service workflows. The platform’s value came from helping teams use the foundation themselves.

Make adoption the evidence

70% of paid buyers used the reporting and analytics capabilities. A shared foundation had become part of how customers worked with their data.
